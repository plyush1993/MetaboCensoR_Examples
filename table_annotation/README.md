# Annotation Comparison Table
The comparison of annotation scope results (isotopes, adducts, and neutral losses) for [`MetaboCensoR`](https://github.com/plyush1993/MetaboCensoR) vs [`mzMine`](https://mzio.io/mzmine-news/), [`CAMERA`](https://www.bioconductor.org/packages/devel/bioc/html/CAMERA.html), [`MS1FA`](https://ms1fa.helmholtz-hzi.de/), and [`nontarget`](https://cran.r-project.org/web/packages/nontarget/index.html).   
Code script and all relevant data are available in the folder.
